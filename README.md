# Nailong Love Website

Website romantis mobile bergaya pastel berdasarkan referensi yang diberikan.
- Nailong before/after memakai aset gambar yang diberikan pengguna.
- Satu bunga diberikan dua kali ke target tangan kiri dan kanan.
- Setelah dua pemberian, Nailong berubah ke ekspresi senang.
- Bagian foto/video masih placeholder untuk diganti pada tahap berikutnya.

Buka `index.html` untuk preview.
